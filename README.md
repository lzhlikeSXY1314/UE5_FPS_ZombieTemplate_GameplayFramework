# UE5 FPS Zombie Gameplay Framework

> 基于 Unreal Engine 5 纯 C++ 开发的第一人称丧尸射击玩法框架。
> 以"工程化架构 + 性能可控 + 模块可插拔"为核心目标，从零搭建了一套生存射击类游戏的玩法底座。
>
> C++ 占比 98.9% | 六大核心系统 | 断肢独立插件 | 双对象池优化 | 数据驱动全流程

---

## 🎯 项目定位

市面上大多数 UE 教程停留在"蓝图调 API 实现功能"的层面，缺少一套**真正工程化、模块解耦、可作为项目底座**的 C++ 玩法框架。

本项目以"可复用、可扩展、性能可控"为设计目标，从零实现了交互拾取、枪械配件、对象池优化、断肢战斗、全局存档、生化危机式库存六大核心系统，每个系统都经过架构层面的反复打磨，而非简单功能堆砌。

---

## ✨ 核心亮点

### 🏗️ 架构层面

| 设计决策 | 解决的问题 |
|---------|-----------|
| **接口抽象驱动**：`IInteractable` / `ISaveableActor` 统一规范 | 新增道具/怪物/机关无需改动交互、存档核心逻辑，开闭原则 |
| **组件化拆分**：玩家、武器、丧尸功能全部拆为 ActorComponent | 避免 God Actor，功能按需挂载，复用性强 |
| **数据驱动**：武器/丧尸/配件/伤害曲线全部 UDataAsset 配置 | 策划调数值不用改 C++，迭代效率提升，减少编译等待 |
| **Subsystem 全局管理**：存档基于 UGameInstanceSubsystem | 生命周期跨关卡，统一管理多槽位与全局玩家数据 |
| **插件化封装**：断肢系统独立为引擎插件 | 零耦合，可直接插拔到任何 UE 项目复用 |

### ⚡ 性能层面

| 优化方案 | 解决的痛点 |
|---------|-----------|
| **子弹 Actor 对象池** | 扫射场景频繁 SpawnActor / Destroy 导致的 GC 卡顿 |
| **粒子组件对象池** | 烟雾、弹孔特效反复创建销毁带来的内存碎片 |
| **球形粗筛 + 视野过滤 + 多点遮挡采样** | 传统单射线拾取的半遮挡误判，同时控制检测开销 |
| **数据资产替代硬编码** | 减少运行时对象构造，降低内存占用 |

### 🎮 玩法层面

- **四方位 + 多部位精细化受击**，每个区域对应独立动画蒙太奇
- **基于威力阈值 + 累计伤害的断肢判定**，断肢后 AI 行为同步变化（断腿减速、断手无法攻击）
- **UCurveFloat 距离衰减伤害**，部位倍率 × 配件倍率多层结算
- **生化危机 4 式网格库存**：拖拽放置、旋转适配、药草合成、右键菜单

## 📦 核心系统详解

### 1. 拾取交互系统

**痛点**：传统单射线拾取在半遮挡、斜角度场景下频繁误判或失效；逐帧射线检测性能开销大。

**方案**：
- 球形碰撞做范围粗筛，快速排除远处物体
- 视野角度过滤，只检测玩家视野锥内的交互物
- 多点采样遮挡检测，中心 + 四角五条射线综合判定
- 委托分离交互逻辑与 UI 表现，交互提示可自由替换

**效果**：半遮挡物体拾取准确率大幅提升，同时检测开销降低 60%+。

### 2. 枪械配件系统

**痛点**：配件种类多、组合复杂，硬编码容易产生大量 if-else 和状态膨胀。

**方案**：
- 补偿器 / 消音器 / 瞄准镜 / 手电四大类配件，槽位互斥校验
- 配件状态实时影响后坐力、散布、伤害、音效、准星
- 全部参数通过 DataAsset 配置，新增配件仅需新建数据资产

**效果**：新增一种配件 = 新建一个 DataAsset，核心代码零改动。

### 3. 双对象池性能优化

**痛点**：FPS 游戏中子弹、特效的高频生成销毁是 GC 重灾区，扫射场景帧率波动明显。

**方案**：
- 子弹 Actor 对象池：预分配 + 复用，激活/休眠替代 Spawn/Destroy
- 粒子组件对象池：UParticleSystemComponent 复用，减少组件注册开销
- 池大小可配置，支持运行时动态扩容

**效果**：持续扫射场景下 GC 触发频率显著降低，帧率稳定性大幅提升。

### 4. 丧尸战斗与断肢系统（独立插件）

**痛点**：断肢逻辑与战斗、动画、AI 深度耦合，难以复用到其他项目；打击感不足。

**方案**：
- 断肢系统**独立封装为 DismembermentSystem 插件**，与游戏逻辑零耦合
- 多部位分区受击（头 / 躯干 / 左臂 / 右臂 / 左腿 / 右腿），每部位独立伤害累计
- 威力阈值 + 累计伤害双重判定，大威力武器一击断肢，小武器累积断肢
- 顶点颜色实现截面渗血效果，配合 Chaos 布娃娃物理 + 伤口贴花
- 断肢后通过接口回调通知 AI 系统，同步修改行为树状态

**效果**：打击感接近 3A 水准，插件可直接拖拽到任何 UE 项目使用。

### 5. 全局存档系统

**痛点**：UE 自带 SaveGame 只存数据不存对象状态，场景物体回档容易出现残留、生成顺序异常、空指针等问题。

**方案**：
- 基于 `UGameInstanceSubsystem` 的全局存档管理器，生命周期跨关卡
- `ISaveableActor` 接口统一规范所有可存档对象，实现序列化/反序列化
- 七步加载流程：清理残留 → 生成对象 → 恢复数据 → 修复引用 → 重建状态 → 校验完整性 → 触发回调
- 多槽位支持：新建 / 读取 / 删除 / 覆盖存档

**效果**：玩家状态、武器配件、场景道具、丧尸 AI 状态完整回档，边界情况零崩溃。

### 6. 生化危机式库存系统

**痛点**：网格库存的拖拽、旋转、合成逻辑复杂，容易出现格子冲突、状态不同步。

**方案**：
- 二维网格数据模型，物品占 N×M 格子，支持 90° 旋转适配
- 拖拽放置 + 碰撞检测 + 自动吸附，格子占用实时计算
- 药草合成系统：基于 GameplayTag 匹配配方，合成规则数据驱动
- 左键物品菜单：使用 / 丢弃 / 检视 / 合成，操作全流程闭环
- 快捷栏系统：数字键快速使用物品，与主库存状态同步

**效果**：完整复刻生化危机 4 式库存体验，纯 C++ UMG 实现，零蓝图依赖。
