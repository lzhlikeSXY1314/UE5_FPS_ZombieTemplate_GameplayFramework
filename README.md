\# UE5 FPS Zombie Gameplay Framework



基于 Unreal Engine 5 纯 C++ 开发的第一人称射击战斗玩法框架，专注于性能优化与数据驱动设计，覆盖拾取交互、枪械配件、丧尸战斗、断肢系统、存档管理五大核心模块。



\## ✨ 项目亮点

\- \*\*全 C++ 实现\*\*：核心玩法逻辑均由 C++ 编写，不依赖蓝图，性能与可维护性更强

\- \*\*组件化+接口解耦\*\*：通过 `IInteractable`、`ISaveableActor` 等接口实现功能解耦，易于扩展

\- \*\*性能优化\*\*：双对象池系统（子弹+烟雾特效）+ 多点遮挡拾取检测，降低战斗场景开销

\- \*\*数据驱动\*\*：武器/丧尸参数均通过 `UDataAsset` 配置，支持快速迭代

\- \*\*完整存档系统\*\*：基于 `UGameInstanceSubsystem` 实现全局存档管理器，支持全场景对象回档

\- \*\*独立插件化\*\*：断肢系统封装为引擎插件，可无缝复用至其他项目



\## 🛠️ 技术栈

\- 引擎：Unreal Engine 5.x

\- 语言：C++17

\- 核心系统：增强输入、Gameplay 框架、Chaos 物理、动画蒙太奇、对象池、UGameInstanceSubsystem

\- 架构思想：接口抽象、组件化、数据驱动、插件化开发



\## 📦 核心模块

\### 1. 拾取交互系统

\- 多点采样遮挡检测，解决传统单射线拾取的半遮挡误判问题

\- 球形范围+视野角度粗筛，兼顾响应速度与性能开销

\- 委托解耦交互逻辑与 UI，支持自定义交互提示



\### 2. 枪械配件系统

\- 支持补偿器/消音器/瞄准镜/手电筒四大可插拔配件，配件间互斥逻辑完善

\- 配件状态实时影响后坐力、散布、伤害、音效、准星等属性

\- 全部参数通过数据资产配置，新增配件无需修改核心逻辑



\### 3. 对象池性能优化

\- 子弹 Actor 对象池：避免高频 `SpawnActor` 带来的性能开销

\- 烟雾特效组件池：复用 `UParticleSystemComponent`，进一步降低内存碎片

\- 有效提升高频射击场景下的帧率稳定性



\### 4. 丧尸战斗与断肢系统

\- 四方位+多部位精细化受击反馈，每个区域对应独立动画蒙太奇

\- 基于威力阈值与累计伤害的断肢判定，断肢后同步影响 AI 行为

\- 顶点颜色实现截面渗血效果，布娃娃物理+贴花系统提升打击感

\- 断肢能力独立封装为 `DismembermentSystem` 插件



\### 5. 数据驱动伤害结算

\- 基于 `UCurveFloat` 实现距离衰减伤害，配合部位/配件乘数结算最终伤害

\- 全部数值可在编辑器内可视化配置，无需修改代码



\### 6. 存档管理系统

\- 多槽位保存/读取/删除，支持玩家状态、武器配件、场景物品、丧尸状态完整回档

\- 七步加载流程，处理回档时对象残留、状态异常等边界问题

\- 通过 `ISaveableActor` 接口统一规范全场景对象存档逻辑
